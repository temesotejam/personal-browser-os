# パーソナルブラウザーOS

ブラウザーの中に、自分専用のデスクトップ環境を作るプロジェクトです。GitHub Pagesで公開できる、ビルド不要の静的Webアプリとして構成しています。

## 主な機能

- デスクトップ画面、アプリ一覧、ドック
- ウィンドウの移動、サイズ変更、最大化、最小化、終了
- 電卓：四則演算と括弧に対応
- ブラウザー：OS内で閲覧・検索。表示できないサイトは確認後に別タブで開けます
- メモ帳：入力内容をブラウザー内に自動保存
- 画像ビューア：端末内の画像を読み込んで表示
- 設定：テーマと壁紙の切り替え
- アプリ追加：Webサイトや自作Webアプリをランチャーに登録
- PWA設定とService Workerによるインストール・オフライン起動の基盤

## ローカルでの起動方法

リポジトリをクローンして、ルートディレクトリでローカルHTTPサーバーを起動してください。

Pythonが使える場合：

    python -m http.server 8000

ブラウザーで http://localhost:8000/ を開きます。

Service WorkerとPWAの動作確認には、localhostまたはHTTPSが必要です。HTMLファイルを直接開く file:// では一部機能が動作しません。

## GitHub Pagesでの公開方法

1. GitHubでこのリポジトリの「Settings」を開きます。
2. 左側の「Pages」を開きます。
3. 「Build and deployment」の「Source」を「Deploy from a branch」にします。
4. ブランチを「main」、フォルダーを「/ (root)」にして保存します。
5. 公開完了後、次のURLでアクセスできます。

   https://temesotejam.github.io/personal-browser-os/

## ブラウザーアプリの注意点

- ブラウザーアプリは、デスクトップ内のウィンドウにWebページを表示する簡易ブラウザーです。
- まずURL入力・検索結果をブラウザーアプリ内に表示します。
- YouTubeやGitHubなど埋め込みが制限されやすいサイトでは、別タブで開くか確認メッセージを表示します。自動では別タブを開きません。
- 読み込み完了が確認できない場合も確認を表示します。どのサイトでも「表示できない場合」ボタンから手動で確認できます。
- 「別タブで開く」を選択したときだけ外部タブを開きます。URLの移動先はHTTPS/HTTPのみです。
- iframeの読み込みイベントは埋め込み拒否を正確に通知しないため、表示失敗の完全な自動検知はできません。確認表示は既知の制限や読み込み未完了に基づく補助機能です。
- Google検索は埋め込み用の `igu=1` パラメーターを利用します（Google公式の恒久的な仕様ではないため、将来変更される可能性があります）。
- Webサイト側がiframeへの埋め込みを禁止している場合、デスクトップ内には表示できません。通常のWebアプリだけでこの制限を解除することはできません。
- 埋め込みページからの自動ポップアップはiframeのsandboxで制限しています。別タブはOS側の確認ボタンから開けます。
- GitHub Pages上のWebアプリから、通常のブラウザーのアドレスバーやタブを完全に置き換えることはできません。

## データとプライバシー

- メモ、外観設定、追加したアプリ情報はlocalStorageに保存されます。
- 保存先は利用中のブラウザー・端末です。別のブラウザーや端末とは自動同期されません。
- 画像ビューアで選択した画像はブラウザー内でプレビューするだけで、サーバーへアップロードしません。
- 追加したWebアプリはサンドボックス化したiframe内で表示します。サイト側の設定（X-Frame-Options / Content-Security-Policy）によっては埋め込みが拒否される場合があります。

## ファイル構成

- index.html — デスクトップの基本構造
- styles.css — デスクトップ、ウィンドウ、アプリのスタイル
- app.js — ウィンドウ管理、アプリ一覧、各アプリの動作
- manifest.webmanifest — PWA設定
- sw.js — アプリ本体のキャッシュ
- assets/icon.svg — アプリアイコン

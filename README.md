# パーソナルブラウザーOS

ブラウザーの中に、自分専用のデスクトップ環境を作るプロジェクトです。GitHub Pagesで公開できる、ビルド不要の静的Webアプリとして構成しています。

## 主な機能

- デスクトップ画面、アプリ一覧、ドック
- ウィンドウの移動、サイズ変更、最大化、最小化、終了
- 電卓：四則演算と括弧に対応
- ブラウザー：OS内で閲覧・検索。表示できないサイトは確認後に別タブで開けます
- **C言語開発環境**：C11のコード編集・コンパイル・実行・標準入力・出力表示、波形・図形描画、Cファイルの読み込み・保存
- **Python開発環境**：CPython 3.14のコード実行、標準入出力、数値計算、グラフ描画、`.py` の読込・保存
- メモ帳：入力内容をブラウザー内に自動保存
- 画像ビューア：端末内の画像を読み込んで表示
- 設定：テーマと壁紙の切り替え
- アプリ追加：Webサイトや自作Webアプリをランチャーに登録
- PWA設定とService Workerによるインストール・オフライン起動の基盤

## ローカルでの起動方法

リポジトリをクローンして、ルートディレクトリでローカルHTTPサーバーを起動してください。

Pythonが使える場合：

    python -m http.server 8000

ブラウザーで http://localhost:8000/ を開きます。

Service WorkerとPWAの動作確認には、localhostまたはHTTPSが必要です。HTMLファイルを直接開く file:// では一部機能が動作しません。

## GitHub Pagesでの公開方法

1. GitHubでこのリポジトリの「Settings」を開きます。
2. 左側の「Pages」を開きます。
3. 「Build and deployment」の「Source」を「Deploy from a branch」にします。
4. ブランチを「main」、フォルダーを「/ (root)」にして保存します。
5. 公開完了後、次のURLでアクセスできます。

   https://temesotejam.github.io/personal-browser-os/

## ブラウザーアプリの注意点

- ブラウザーアプリは、デスクトップ内のウィンドウにWebページを表示する簡易ブラウザーです。
- まずURL入力・検索結果をブラウザーアプリ内に表示します。
- YouTubeやGitHubなど埋め込みが制限されやすいサイトでは、別タブで開くか確認メッセージを表示します。自動では別タブを開きません。
- 読み込み完了が確認できない場合も確認を表示します。どのサイトでも「表示できない場合」ボタンから手動で確認できます。
- 「別タブで開く」を選択したときだけ外部タブを開きます。URLの移動先はHTTPS/HTTPのみです。
- iframeの読み込みイベントは埋め込み拒否を正確に通知しないため、表示失敗の完全な自動検知はできません。確認表示は既知の制限や読み込み未完了に基づく補助機能です。
- Google検索は埋め込み用の `igu=1` パラメーターを利用します（Google公式の恒久的な仕様ではないため、将来変更される可能性があります）。
- Webサイト側がiframeへの埋め込みを禁止している場合、デスクトップ内には表示できません。通常のWebアプリだけでこの制限を解除することはできません。
- 埋め込みページからの自動ポップアップはiframeのsandboxで制限しています。別タブはOS側の確認ボタンから開けます。
- GitHub Pages上のWebアプリから、通常のブラウザーのアドレスバーやタブを完全に置き換えることはできません。

## C言語開発環境の使い方

デスクトップの「C言語開発」またはランチャーから起動します。単独では `c-ide/index.html` からも開けます。

1. 「Hello World」「数値計算」「入力と計算」「図形・波形描画」からサンプルを選びます。
2. コードを編集し、「▶ コンパイルして実行」を押します（Ctrl+Enterも利用可能）。
3. コンパイル結果と標準出力はコンソールに表示されます。`scanf` などの入力値は先に「標準入力」欄へ記入してください。
4. 「図形・波形描画」では C の `printf` で独自の描画命令を出力すると、同じウィンドウ内のCanvasへ表示されます。
5. 編集内容はブラウザーに自動保存され、「保存」から `.c` ファイルをダウンロードできます。

描画命令の例：

```c
puts("@PLOT CLEAR 640 360");
puts("@PLOT LINE 30 30 550 300 #7367ff");
puts("@PLOT CIRCLE 200 140 24 #fb7185");
puts("@PLOT RECT 280 50 100 75 #22c55e");
```

描画はパーソナルOS独自の拡張であり、標準CのグラフィックAPIではありません。コンソール出力も残ります。

コンパイラは **Clang 18.1.2 + wasi-libc** を WebAssembly で動かします。初回は約70MBのツールチェーンがブラウザーに読み込まれ、Cソースコードはコンパイルサービスへ送信されません。コンパイル・実行は端末内で行います。実行に時間がかかりすぎるプログラムは10秒で停止します。

コンパイラ本体は GitHub Actions の `install-c-toolchain.yml` で、[Derle](https://github.com/senolgulgonul/derle) が公開するLLVM・WASIビルドを検証してから `c-ide/toolchain/` に配置しています。実行時にはこのリポジトリから配信されるファイルのみ使用します。ClangはApache-2.0 WITH LLVM-exception、wasi-libcはApache-2.0/MITです。OSや実機のシステムコール、Windows用プログラム、ネイティブGUIは対象外です。

## Python開発環境の使い方

OSの「🐍 Python開発」を起動します。または `python-ide/` を直接開いても利用できます。

1. 「Hello World」「数値計算」「標準入力」「グラフ描画」からサンプルを選択します。
2. 「▶ 実行」を押します。Ctrl+Enterでも実行できます。初回はPython実行環境の読み込みが必要です。
3. `input()` は実行前に「標準入力」欄に入力してください。
4. グラフは標準ライブラリの `math` と、OS専用の `os_plot` を組み合わせて描画できます。
5. `.py` ファイルの読込・保存、ブラウザー内の自動保存、PNG画像保存に対応しています。

グラフ描画の例：

```python
import math
from os_plot import plot, title, grid

x = [i * 0.1 for i in range(63)]
y = [math.sin(v) for v in x]
plot(x, y, "#7367ff")
title("sin(x)")
grid(True)
```

`os_plot` は独自の軽量グラフ機能で、`plot`, `scatter`, `bar`, `title`, `xlabel`, `ylabel`, `grid`, `clear` を提供します。標準のmatplotlibとは異なります。

Pythonランタイムは [Pyodide 314.0.7](https://pyodide.org/en/stable/)（Python 3.14）を利用します。`.github/workflows/install-python-runtime.yml` が固定バージョンのランタイムを取得して `python-ide/vendor/` に配置します。**コード実行のための外部コンパイルサーバーは不要**で、プログラムはWeb Worker内で実行されます。無限ループ対策として実行開始から12秒で停止させます。初回はランタイムのダウンロードが必要ですが、その後はブラウザーのHTTPキャッシュを利用します。

**制限：** ブラウザー内のPythonなので、Windowsの実行ファイルや任意のPC上のファイルを直接操作することはできません。標準ライブラリの多くは利用できますが、一部のモジュール、OS固有機能、外部の拡張パッケージは対応しません。

## データとプライバシー

- メモ、外観設定、追加したアプリ情報はlocalStorageに保存されます。
- 保存先は利用中のブラウザー・端末です。別のブラウザーや端末とは自動同期されません。
- 画像ビューアで選択した画像はブラウザー内でプレビューするだけで、サーバーへアップロードしません。
- 追加したWebアプリはサンドボックス化したiframe内で表示します。サイト側の設定（X-Frame-Options / Content-Security-Policy）によっては埋め込みが拒否される場合があります。

## ファイル構成

- index.html — デスクトップの基本構造
- styles.css — デスクトップ、ウィンドウ、アプリのスタイル
- app.js — ウィンドウ管理、アプリ一覧、各アプリの動作
- manifest.webmanifest — PWA設定
- sw.js — アプリ本体のキャッシュ
- assets/icon.svg — アプリアイコン
- c-ide/ — C言語開発環境（コードエディタ、WASI実行環境、コンパイラ）
- python-ide/ — Python開発環境（Pyodide、エディタ、グラフ描画、Web Worker）
- .github/workflows/install-c-toolchain.yml — ビルド済みコンパイラの検証・配置
